# খাদিজা পাঠশালা

বাংলাদেশের শিক্ষার্থীদের জন্য শ্রেণি ও বিষয়ভিত্তিক পাঠ্যবই খোঁজার বাংলা ওয়েবসাইট। SSC ও HSC-এর কিছু বইয়ের PDF NCTB-র প্রকাশিত আর্কাইভ লিংক থেকে অনলাইন reader-এ খোলে।

## প্রকাশনা

এই সাইট GitHub Pages দিয়ে প্রকাশিত:

https://jibidkumar44-stack.github.io/khadiza-pathshala/

## উৎস ও সংস্করণ

SSC-এর সংযুক্ত PDF লিংক NCTB-এর ২০২২ আর্কাইভ এবং HSC-এর লিংক ২০২১–২২ আর্কাইভ থেকে নেওয়া। এগুলো বর্তমান সংস্করণ নাও হতে পারে। সর্বশেষ বই ও শিক্ষাবর্ষ যাচাই করতে [NCTB](https://nctb.gov.bd/) দেখুন।

বইয়ের PDF এই repository-তে কপি করা হয়নি; কার্ডের লিংক NCTB-র প্রকাশিত ফাইল বা উৎসে নিয়ে যায়।
